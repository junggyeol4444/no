## 명세에 없어 구현에서 정한 값 (검토 요청, SPEC 12-4)

- **종별 고정 스킬 목록**: SPEC T1-2 는 "종별 고정 목록에서 4개"라고만 하고
  목록을 주지 않는다. 되돌이 프로토타입을 검증 가능하게 하려면 각 종의
  4스킬 배정이 필요해, 다음과 같이 정했다 (`monster.c: species_default_moves`):
  - 1 불꽃도마뱀: 들이받기(1)·불꽃송곳니(2)·화염폭발(6)·야성의송곳니(8)
  - 2 물뱀: 들이받기(1)·물대포(3)·단단해지기(5)·야성의송곳니(8)
  - 3 새싹짐승: 들이받기(1)·덩굴채찍(4)·바위깨기(7)·야성의송곳니(8)

  기준: 각 종에 자속 공격기 + 조건기(우성/열성) + 되돌이 전용기(ID 8)를
  넣어 되돌이·유전자 조건·자속을 모두 관찰할 수 있게 했다. **게임 값이므로
  기획 확정 시 교체 가능.**

- **자동 대전 레벨 = 50**: SPEC 은 자동 대전 개체 레벨을 명시하지 않는다.
  스토리 초반 지역대(SPEC 15-2 Lv2~24)와 무관한 임의값이다. 아래 P1 측정의
  전제이며, 재측정 시 조정 대상이다.

## 명세와 다르게 하지 않은 것 (SPEC 12-3 준수)

- 6-7 되돌이 타이밍의 `[검증필요]`(즉시 vs 턴종료)는 임의로 정하지 않고
  **둘 다** 구현해 `--awaken-timing` 으로 시험 가능하게 했다(SPEC 6-7 지시대로).
- 손계산 케이스(9-1 A/B/C)는 명세의 일부로 두고 구현을 거기에 맞췄다.
  테스트를 고쳐 통과시키지 않았다(SPEC 12-5).

## 발견한 문제

- **전투가 너무 짧다(평균 ~2.5턴)**: base 45~55 종족값 개체를 Lv50 으로 붙이면
  데미지/HP 비가 커서 2~3턴에 끝난다. 25% 되돌이 구간을 거치기 전에 즉사하는
  경우가 많아 되돌이의 긴장감이 잘 드러나지 않는다. 상세·수치는
  [`P1_FINDINGS.md`](P1_FINDINGS.md) 참조. → SPEC 13-3 의 "애매하다: 임계값·
  타이밍을 바꿔 재측정" 또는 전투 파라미터(레벨/종족값/위력) 재검토가 필요하다.
  전투 구조 자체(2×2, 데미지식)는 P1 범위상 손대지 않았다(SPEC 27-3).
